# Botmother — Telegram Serverless + DeepSeek

نسخهٔ جدید Botmother روی Telegram Serverless اجرا می‌شود. عامل مشاوره و ساخت سورس از DeepSeek استفاده می‌کند و کاربران با ثبت داوطلبانهٔ کلید در Mini App وارد استخر مشارکتی می‌شوند.

## منطق استخر

- هر کاربر یک کلید DeepSeek ثبت می‌کند؛ کلید در پیام چت دریافت نمی‌شود.
- پیش از ثبت، کاربر صریحاً تأیید می‌کند که کلیدش برای درخواست‌های اعضای دیگر هم استفاده خواهد شد.
- درخواست‌ها با روش کمترین‌استفادهٔ اخیر بین کلیدهای آماده می‌چرخند؛ هر کلید هم‌زمان فقط یک درخواست می‌گیرد.
- پاسخ 429 موجب توقف موقت همان کلید می‌شود. کلید نامعتبر از استخر کنار گذاشته می‌شود.
- کاربر می‌تواند کلیدش را از Mini App حذف یا جایگزین کند. یک کلید فقط به یک حساب تلگرام وصل می‌شود.
- کلیدها با AES-GCM در پایگاه Telegram Serverless ذخیره می‌شوند. کلید رمزنگاری pool در `.env` محلی تولید می‌شود؛ از آن فایل پشتیبان بگیر و آن را در Git قرار نده.
- فایل تنظیمات runtime برای رمزگشایی روی همان پروژه قرار می‌گیرد؛ دسترسی CLI پروژه را فقط به مدیران مورد اعتماد بده.

## نصب و انتشار

1. در BotFather، همین ربات را باز کن و `Serverless` را روشن کن. از بخش `CLI Access`، توکن دسترسی Serverless را بگیر؛ این توکن با Bot API token فرق دارد.
2. در ریشهٔ پروژه، `npm install` و سپس `npx tgcloud login` را اجرا کن.
3. `npm run configure:serverless` را اجرا کن. این دستور شناسهٔ برنامه را از ورود CLI می‌خواند، نشانی Mini App را می‌سازد و کلید رمزنگاری محلی را در `.env` نگه می‌دارد.
4. `npm run deploy` را اجرا کن تا کد و Mini App منتشر شوند.
5. برای ساخت جدول‌های اولیه، `npm run migrate` را اجرا و تغییرها را تأیید کن.
6. در تلگرام `/start` را بزن. Mini App ثبت کلید و رضایت را انجام می‌دهد؛ بعد از تأیید، منوی ساخت ربات باز می‌شود.

کلید رسمی DeepSeek: [ساخت یا مدیریت کلید API](https://platform.deepseek.com/api_keys)

## فرمان‌ها

- `/start` شروع یا بازگشت به منو
- `/new` شروع ایدهٔ تازه
- `/pool` نمایش وضعیت کلید مشارکتی خودت
- `/help` راهنما

## معماری و محدودیت

- `tgcloud/handlers/` شامل handlerهای پیام و callback است.
- `tgcloud/endpoints/` ثبت، حذف و نمایش وضعیت کلید را از Mini App میزبانی می‌کند. Telegram اطلاعات `initData` را پیش از اجرای endpoint اعتبارسنجی می‌کند.
- `tgcloud/lib/pool.js` رمزگذاری کلیدها، انتخاب چرخشی، شمارش مصرف و cooldown را مدیریت می‌کند.
- `webapp/index.html` رابط راست‌به‌چپ برای ثبت کلید با فیلد مخفی و رضایت صریح است.
- فایل‌های قدیمی Cloudflare در `src/` و `wrangler.toml` برای مرجع باقی مانده‌اند؛ نسخهٔ جدید از آن‌ها استفاده نمی‌کند.
- هر پروژهٔ Telegram Serverless به یک ربات وصل است. Botmother خودش روی Serverless اجرا می‌شود و فایل سورس ربات‌های ساخته‌شده را تحویل می‌دهد؛ انتشار ربات‌های دیگر از داخل همین پروژه خودکار نیست.
- برای CI از GitHub Actions، secrets به نام‌های `TGCLOUD_TOKEN` و `POOL_ENCRYPTION_KEY` لازم است. پس از تغییر schema، migration را جداگانه از CLI یا BotFather اعمال کن.

## فایل‌ها

```text
tgcloud/
  endpoints/       # ثبت، حذف و وضعیت کلیدهای pool
  handlers/        # پیام‌ها و دکمه‌های ربات
  lib/             # عامل DeepSeek، رمزگذاری و چرخش کلید
  schema.js        # جدول‌های وضعیت و کلید
webapp/index.html  # Mini App برای ورود رضایت‌مندانه به pool
scripts/           # ساخت تنظیمات محلی خارج از Git
tgcloud.jsonc      # میزبانی Mini App
```
